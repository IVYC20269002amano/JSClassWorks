# Description

パーソナルで利用可能なツール集です。
※CSSはAIに適当に作らせてただけです

## Outline

- 簡易パスワードジェネレーター
- ファイルシュレッダー
- ファイル事前暗号化シールド
- キーストロークバイオメトリクスラボ

### パスワードジェネレーター

簡易パスワードジェネレーターです。
ステータスバーは生成文字数を決めます。4～64文字以内です。
チェックボックスで大文字、数字、記号を含むかどうかを選べます。

### ファイルシュレッダー

簡易上書きツールです。
指定したファイルのバイト数を計測し、乱数で上書きした同名のファイルをダウンロードします。
最後に手動で元のファイルに上書きします。
（本当はオール０，オール１、で上書きした後が良いのですが、現状はこうなっています）

### ファイル事前暗号化シールド

ゼロトラストの考え方を踏襲し、クラウドストレージ等に保存や移動をする前にそのファイルを暗号化します。

### キーストロークバイオメトリクスラボ

AIか人間かを判定するためのキー計測を行います。
現状は単なる計測データを出力するだけです。

## 常に意識すること

1.  変数の名前は、TMPやINPUT、OUTPUTを意識した命名にすること。

2.  そしてそれをソースの最初にルールとして書いておくこと。

3.  見られたくないものは、変数使用後に初期化を必ずラストに入れること。

## 改善点

### 早めに着手

1.  スコープの範囲を常に念頭に置く。出来る限りグローバルは避け隠蔽すること。
    ➝実装済み

2.  パスワードを数種類提示し、そこから選ばせる機能
    ➝実装済み

3.  チェックを入れたものは、必ず最低でも１種以上選ばれること。
    ➝実装済み

### 他の前提条件を満たしてから着手

1.  人間が実際に使いやすい（覚えやすい）パスワードを多めに提示すること
    ➝前提条件：DB、サーバー知識

2.  以前同じパスワード、もしくは近いパスワードを生成していた場合、それを避ける機能
    ➝前提条件：DB、サーバー知識

3.  高難度の暗号化を取り入れること
    ➝前提条件：暗号化ツール作成後
